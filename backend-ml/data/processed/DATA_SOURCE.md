# Historical cases data source

`cases_clean.csv` is the processed subset used by the outcome analytics and similar-case endpoints.
It was prepared from the Kaggle Jud-IPL Indian Legal Judgement Prediction Dataset:
https://www.kaggle.com/datasets/bhavyabj/jud-ipl-indian-legal-judgement-prediction-dataset

The Kaggle listing identifies the dataset license as CC0 (public domain). The cleaned file retains only the case identifier, category, type, and outcome label; it excludes full judgment text. Dataset descriptions and attribution should be checked against the source listing when redistributing.

The project model is experimental and is not legal advice.
